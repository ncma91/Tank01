# Anhang C – Glossar

| Begriff | Erklärung |
|---|---|
| **Boustrophedon** | „Wie der Ochse pflügt“ – Mähmuster mit parallelen Bahnen in wechselnder Richtung |
| **b_eff** | Effektive Arbeitsbreite = Arbeitsbreite × (1 − Überlappung) |
| **BMS** | Battery Management System – überwacht Zellen, Strom, Temperatur |
| **Costmap** | Rasterkarte mit Befahrungskosten (0 = frei, 254 = Hindernis) in Nav2 |
| **Datum** | Fester geografischer Bezugspunkt, Ursprung des lokalen `map`‑Koordinatensystems |
| **DDS** | Data Distribution Service – Middleware von ROS 2 |
| **EKF** | Extended Kalman Filter – fusioniert Sensordaten zur Zustandsschätzung |
| **ENU** | East‑North‑Up – lokales kartesisches Koordinatensystem |
| **Geofence** | Virtuelle Grenze, die das Fahrzeug nicht verlassen darf |
| **Heading** | Fahrzeugausrichtung (Gierwinkel) relativ zu Ost (ROS) bzw. Nord (Navigation) |
| **Headland / Vorgewende** | Randstreifen eines Feldes, in dem gewendet wird |
| **KISS‑ICP** | Einfache, robuste LiDAR‑Odometrie (Iterative Closest Point) |
| **Moving Base** | GNSS‑Konfiguration mit zwei Empfängern am Fahrzeug zur Heading‑Bestimmung |
| **MPPI** | Model Predictive Path Integral – stichprobenbasierter Bahnregler in Nav2 |
| **Nav2** | Navigations‑Framework für ROS 2 |
| **NTRIP** | Networked Transport of RTCM via Internet Protocol – Korrekturdaten über Internet |
| **PL / Kat.** | Performance Level / Kategorie nach EN ISO 13849‑1 |
| **PTP** | Precision Time Protocol (IEEE 1588) – Zeitsynchronisation über Ethernet |
| **RTK** | Real Time Kinematic – GNSS mit cm‑Genauigkeit durch Trägerphasen‑Korrektur |
| **RTK‑Fix / Float** | Mehrdeutigkeiten gelöst (cm) / nicht gelöst (dm) |
| **Schlegelmulcher** | Mähwerk mit pendelnd aufgehängten Schlegeln auf horizontaler Welle |
| **Skid‑Steer** | Lenkung durch unterschiedliche Geschwindigkeit linker/rechter Seite |
| **STVL** | Spatio‑Temporal Voxel Layer – 3D‑Costmap‑Layer mit zeitlichem Zerfall |
| **Swath / Streifen** | Eine gerade Mähbahn |
| **TF** | Transform‑Bibliothek von ROS (Koordinatentransformationen) |
| **Traversierbarkeit** | Befahrbarkeit einer Geländezelle (Neigung, Stufe, Rauigkeit, Untergrund) |
| **Turasrad** | Antriebskettenrad eines Kettenlaufwerks |
| **VESC** | Open‑Source‑BLDC‑Motorregler mit CAN‑Schnittstelle |
| **Watchdog** | Überwachung, die bei ausbleibendem Lebenszeichen einen sicheren Zustand herstellt |
